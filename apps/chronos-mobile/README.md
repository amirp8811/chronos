# CHRONOS mobile client scaffold

This directory is a planning scaffold. It does not contain a buildable mobile
client, network transport, key-management integration, or supported release.

## Status

| Area | Status |
| --- | --- |
| Directory layout | Present |
| Native project files | Not implemented |
| Secure platform key storage | Planned |
| Transport adapter | Planned |
| Background execution policy | Planned |
| Production mobile client | Unsupported |

Future work must begin with a concrete threat model, reviewed key lifecycle,
identity-distribution design, and reproducible transport tests. Do not represent
this directory as an application or a privacy service.
